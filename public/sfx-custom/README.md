# Custom SFX

Taruh file audio (.wav, .mp3, .ogg) di folder ini.

Cara pakai di UI:
1. Pilih element di form
2. Set **SFX** dropdown → "custom"
3. Isi **sfx file** dengan nama file (misal: `cinematic-impact.wav`)

File akan diputar saat element muncul.

## Format yang didukung

- `.wav` (recommended untuk Remotion)
- `.mp3`
- `.ogg`
- `.m4a`

## Naming convention

Gunakan nama deskriptif:
- `cinematic-impact.wav`
- `whoosh-fast.wav`
- `boom-low.wav`
- `riser-buildup.wav`

## Tips

- File pendek 0.3-1.5 detik ideal
- Sample rate 44.1kHz atau 48kHz
- Mono channel lebih kecil
- Normalize volume (-3dB peak) sebelum pakai
